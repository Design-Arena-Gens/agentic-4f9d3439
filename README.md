# TV-Finder Schweiz

Web-App, die das beste 55" TV-Modell 2025 auswählt (kuratiert) und Schweizer Händlerseiten heuristisch nach Preis und Lieferbarkeit bis zum nächsten Dienstag prüft.

- Stack: Next.js 14 (App Router), TypeScript, Cheerio, Undici
- Starten: `npm install && npm run build && npm start`
- API: `GET /api/find`

Hinweis: Heuristisch – bitte finale Verfügbarkeit auf Händlerseiten prüfen.
